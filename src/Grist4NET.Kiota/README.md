# Grist4NET.Kiota

[Kiota](https://learn.microsoft.com/en-us/openapi/kiota/overview)-generated API client from [Grist's](https://www.getgrist.com/) [OpenAPI spec](https://support.getgrist.com/api/).

For more resources, visit the [Grist4NET documentation site](https://g4n.dj1.dev/) or [project repository](https://codeberg.org/dj1/Grist4NET).
